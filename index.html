Front End Development

რა არის პროგრამირება?

პროგრამირება არის კომპიუტერისთვის სპეციალური ინსტრუქციების დაწერის პროცესი. პროგრამები სხვადასხვა პროგრამირების ენას იყენებს იმისთვის, რომ შექმნას ვებგვერდები, მობილური აპლიკაციები, თამაშები და სხვა პროგრამები.

HTML

HTML — ვებგვერდის სტრუქტურის შესაქმნელად გამოიყენება. მისი დახმარებით ვამატებთ ტექსტს, სათაურებს, სურათებს, ღილაკებს, ბმულებს და სხვა ელემენტებს.

CSS

CSS — ვებგვერდის დიზაინისა და ვიზუალური მხარის შესაქმნელად გამოიყენება. მისი დახმარებით შეგვიძლია შევცვალოთ ფერები, ზომები, შრიფტები, დაშორებები და ელემენტების განლაგება.

HTML + CSS

HTML ქმნის ვებგვერდის სტრუქტურას, ხოლო CSS ამ სტრუქტურას აძლევს ლამაზ და მოწესრიგებულ დიზაინს.
